Mifos X operations, native to Odoo

A reviewed operator workspace backed by Apache Fineract.

Work with clients, groups, centers, loans, savings, products and ledger catalogs. Submit 21 typed operations for independent approval. Review schedules, balances, transactions, charges and table reports.

Every financial request retains its maker, checker, payload hash and remote audit references. Unknown outcomes require reconciliation and are never retried automatically.

Requires Odoo 20 Community and a separate Fineract service. See the repository coverage contract for supported workflows and remaining Mifos X features.
