MFIERP — Mifos X Operations
===========================

Native Odoo 20 Community portfolio and operation screens backed by Apache
Fineract. Supports 21 typed commands, separate makers/checkers, company/tenant
isolation, immutable command payloads, durable dispatch reservation and manual
reconciliation. Fineract remains the financial authority.

This addon requires a separately deployed Fineract API and environment-based
service credentials. It does not implement every Mifos X feature. See the
coverage, architecture, deployment and validation documents in the source repo:

https://github.com/nandahtoon/MFIERP
